CÓMO PUBLICARLA O ACTUALIZARLA (GitHub Pages, desde el celular)
  1. Descomprime el zip.
  2. Entra a tu repositorio en github.com.
  3. Add file → Upload files. Sube index.html, sw.js y manifest.webmanifest
     (reemplazan a los anteriores).
  4. Si es la primera vez o cambiaste de versión: abre la carpeta icons,
     Add file → Upload files y sube los 5 archivos PNG.
  5. Commit changes. En 1 o 2 minutos queda publicada.
  6. En el celular abre la app dos veces: la primera descarga la versión nueva y
     la segunda ya la usa. Si aparece el aviso "Hay una versión nueva", toca
     "Actualizar". La versión instalada se ve abajo de todo en Ajustes.


PARA JUGAR CON AMIGOS (EN LÍNEA)
  - Todos los jugadores deben tener la misma versión del juego en línea (NETV).
    Si alguien tiene una más vieja, la sala lo avisa y no deja empezar. NETV solo
    cambia cuando cambian las preguntas o las reglas: la 3.4 NO juega en línea
    con la 3.3 o anteriores porque cambió el banco de preguntas.
  - Las fotos se guardan en la misma base de datos, en salas con el final «-av»,
    y se borran cuando el jugador sale. No hace falta cambiar las reglas de
    Firebase: las de abajo ya las permiten.
  - Usa tu base de datos de Firebase (Realtime Database). Si "Con amigos" dice
    "No se pudo conectar" teniendo internet, entra a la consola de Firebase →
    Realtime Database → Reglas. Estas reglas permiten jugar y no dejan listar
    todas las salas (si ya te funciona, no cambies nada):

      {
        "rules": {
          "rooms": {
            "$room": {
              ".read": true,
              "$player": { ".write": true }
            }
          }
        }
      }

    (Las reglas del "modo de prueba" de Firebase vencen a los 30 días.)


LEER LA REINA-VALERA 1960 DENTRO DE LA APP (OPCIONAL)
  El texto de la RVR1960 tiene derechos de autor (Sociedades Bíblicas Unidas), por
  eso NO está dentro de la app. Se puede mostrar bajándolo de la Plataforma de
  YouVersion, que es gratuita para apps sin fines de lucro y sin anuncios:
  1. Regístrate y crea tu app en platform.youversion.com. Acepta la licencia de la
     Reina-Valera 1960 si te la ofrece. Copia la clave (App Key); no es secreta.
  2. En la app: Ajustes → «Reina-Valera 1960 dentro de la app (avanzado)» → pega la
     clave → Probar. Si dice ✅ funciona en tu teléfono.
  3. Para que les funcione a todos, la clave va en index.html, en  const YVK="…"
     (entre las comillas); subes de versión (APPV y VER). Si cambias de clave,
     cambia ese texto. Mientras tanto cada persona puede pegarla en su Ajustes.
  El texto se baja al tocar el botón, se muestra con el aviso de derechos que manda
  YouVersion y no se guarda en el teléfono. Para usar la RVR1960 de otra forma
  (por ejemplo, dentro de la app sin internet) hay que pedir permiso por escrito a
  la American Bible Society (licensing@americanbible.org).


PARA AGREGAR PREGUNTAS
  En index.html busca  const BANK=  Cada línea es una pregunta:

    nivel|pregunta|respuesta correcta|error1;error2;error3|Libro capítulo:versículo

  Nivel: 0 fácil, 1 intermedio, 2 difícil. El libro debe escribirse como en la
  Biblia (por ejemplo: 1 Samuel 17:49). Si agregas texto de un versículo, va en
  la lista que empieza en  const VERSES=
  Los versículos de verses.txt son el texto exacto de la Reina-Valera 1909
  (fuente: scrollmapper/bible_databases en GitHub, SpaRV). Solo se usa texto de
  dominio público.
  Importante: cada vez que cambies las preguntas, sube también el número de
  versión (APPV y NETV en index.html, y VER en sw.js), así todos se actualizan y
  el modo con amigos sigue sincronizado. Si solo cambias el diseño, sube APPV y
  VER pero deja NETV como está.
